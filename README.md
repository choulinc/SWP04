# 貼一下 · 便利貼看板

[開啟線上看板](https://choulinc.github.io/SWP04/) · 純 HTML、CSS、JavaScript，資料保存在目前瀏覽器的 LocalStorage。

原有功能包括新增六色便利貼、編輯、刪除、刪除復原、搜尋、顏色篩選，以及拖曳或使用按鈕調整排列。內容、顏色與排列在重新整理後仍會保留。

## 這次新增的 20 個功能

1. **置頂**：重要便利貼固定排在前面。
2. **收藏**：將想保留的想法加上星號。
3. **標籤**：在編輯視窗為便利貼加上最多八個標籤。
4. **核取清單**：拆分步驟並記錄完成狀態。
5. **到期日**：指定日期並在貼紙上顯示。
6. **優先級**：設定高、中、低優先。
7. **封存與還原**：將貼紙移出目前看板，日後仍可取回。
8. **複製便利貼**：快速建立內容相似的新貼紙。
9. **自訂顏色**：除了六種預設色，也能選擇自己的顏色。
10. **排序方式**：依手動順序、建立時間、修改時間、到期日或優先級排列。
11. **清單視圖**：切換看板與單欄清單。
12. **深色模式**：切換外觀並記住偏好。
13. **匯出備份**：下載所有便利貼的 JSON 備份。
14. **匯入備份**：合併 JSON 備份，跳過相同 ID。
15. **列印看板**：使用適合紙張的列印版面。
16. **逾期篩選**：集中查看已過到期日的便利貼。
17. **收藏篩選**：只看加星號的便利貼。
18. **多選**：選取目前結果中的多張貼紙。
19. **批次刪除**：一次刪除選中的貼紙，仍可復原。
20. **批次換色**：一次更換選中貼紙的顏色。

編輯便利貼可設定標籤、核取清單、到期日、優先級與自訂顏色。按 `N` 可聚焦新增欄，按 `/` 可聚焦搜尋欄。

## 本機使用

在專案目錄執行 `python3 -m http.server 8000`，再開啟 `http://localhost:8000`。

## 部署與資料

推送到 `main` 分支後，`.github/workflows/deploy.yml` 會部署到 GitHub Pages。LocalStorage 不會跨裝置同步，建議定期使用「匯出備份」。
