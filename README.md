# 貼一下 · 便利貼看板

使用純 HTML、CSS 與 JavaScript 製作的便利貼看板。可新增六種顏色的便利貼、編輯標題和內容、刪除及復原，並以拖曳或移動按鈕調整順序。內容、顏色與排列保存在瀏覽器 LocalStorage，重新整理或再次開啟網站後仍會保留。

[開啟線上看板](https://choulinc.github.io/SWP04/)

## 本機使用

在專案目錄執行 `python3 -m http.server 8000`，再開啟 `http://localhost:8000`。也可以直接開啟 `index.html`。

## 使用方式

1. 在左側填寫內容、選擇顏色，按「貼上看板」。標題可以留空。
2. 點便利貼內容或編輯按鈕可修改；刪除後可在畫面右下角按「復原」。
3. 桌面可拖曳便利貼排序；各張便利貼上也有向前、向後移動按鈕，手機或鍵盤操作時同樣可用。
4. 搜尋或按顏色篩選便利貼。

資料只保存在目前瀏覽器與網站來源，不會跨裝置同步。

## 部署

推送到 `main` 分支後，`.github/workflows/deploy.yml` 會將靜態檔案部署到 GitHub Pages。
